스타일가이드

흑백의 깨끗한 액자 위에 파스텔 색 면을 한 장씩 붙이는 디자인 언어다. 화면의 주인공은 아이의 작품이고, 인터페이스는 그 작품을 걸어 두는 벽이 된다.

기준: design/style-guide/DESIGN.md — npx getdesign@latest add figma로 받은 Figma 디자인 분석(alpha). 토큰 값은 원문 그대로 쓴다. 우리 아이 미술관 화면에 맞춘 부분은 적용 예시 — 제안 으로 따로 표시한다. 사용법은 스타일가이드_메뉴얼_우리아이미술관.md를 본다.

01 · 원칙

작품이 먼저 보이게

Figma 디자인 언어의 여섯 가지 규칙을 우리 서비스의 약속과 한 줄씩 짝지었다.

흑백 프레임

내비게이션, 본문, 버튼은 검정과 흰색만 쓴다. 색은 아이의 작품에서 나오게 둔다.

컬러 블록 = 이야기 구간

색 면은 장식이 아니라 구간 표시다. 한 화면에 하나만 두고, 사이에는 흰 여백을 둔다.

알약 버튼

글자 버튼은 모두 알약, 아이콘 버튼은 모두 원이다. 네모 버튼은 없다.

굵기로 위계

회색 글자를 쓰지 않는다. 같은 크기에서 굵기(320 → 480 → 540)로 강조한다.

모노체는 분류에만

상태, 연령 묶음, 날짜 같은 분류 라벨에만 모노체 대문자를 쓴다. 문장은 쓰지 않는다.

그림자 대신 색 면

강조는 그림자가 아니라 배경 색 면으로 한다. 그림자는 떠 있는 메뉴와 모달에만 쓴다.

02 · 색

색 토큰 20개

대비 값은 WCAG 2.1 기준으로 계산했다. 검정 글자는 모든 파스텔 블록에서 AA를 넉넉히 넘는다.

브랜드 · 글자

표면

컬러 블록

강조 · 의미

주의 — 흰 글자 + 마젠타는 3.34:1이라 본문(4.5:1)에는 못 쓰고 20px 이상 버튼 글자에만 쓴다. 성공 초록(3.18:1)은 글자가 아닌 체크 아이콘에만 쓴다. 헤어라인(1.25:1)은 입력칸 경계로는 약하므로 입력칸은 초점 링으로 상태를 보완한다(메뉴얼 §4.3 제안).

03 · 타이포그래피

한 목소리, 여러 굵기

figmaSans와 figmaMono는 공개 서체가 아니라서 DESIGN.md가 권하는 대체 서체를 쓴다. 영문·숫자는 Inter, 한글은 Pretendard, 라벨은 JetBrains Mono다.

06 · 적용 예시 제안

우리 아이 미술관 화면

명세(spec v2.1)와 업무규칙을 지키도록 Figma 언어를 옮긴 예시다. 점수는 보이지 않고, 원본 액자에 실패 표시를 붙이지 않으며, 아이의 한마디와 AI 설명을 섞지 않는다.

판정 제안과 보호자 확정

이 작품은 움직이는 그림으로 만들어 볼까요? 다른 방식도 고를 수 있어요.

점수·확률은 보이지 않는다(BR-SUG-02). 제안은 "제안" 라벨 하나로만 표시하고 다른 선택을 막지 않는다(BR-SUG-03).

처리 상태

접수됨 처리 중 다시 시도하는 중 확인 대기 처리하지 못했어요

상태는 색이 아니라 모노체 라벨과 점 모양으로 구분한다. 빨강·노랑 같은 새 강조색을 들이지 않는다. 상태 배지와 낮춤 안내는 진행·결과 확인 화면(UC3·UC4)에서만 보인다. 전시 화면에는 낮춤 원인과 결과 원인을 표시하지 않는다(D3 · BR-EXH-07).

가족 전시 — 아이별 · 연령 묶음 · 제작일 순

원본 액자도 움직이는 그림과 같은 크기, 같은 카드로 건다. "실패"·"대체" 표시를 붙이지 않는다(BR-EXH-04). 재생은 고를 때만 한다(BR-EXH-03).

06-1 · 상태 컴포넌트 시안 · D22 · 신지현 검토

막힘은 색이 아니라 모양으로

SD_02 §3-5의 사상을 그대로 그린 시안이다. 빨강은 쓰지 않고, 마젠타는 상태에 쓰지 않는다. 차단은 굵은 실선, 보류는 점선과 크림 면, 종결은 회색 면이다. 모든 상태는 문구를 함께 적는다.

준비됨 미준비 불러오는 중 12초 / 약 20초 적재 실패 · 60초마다 다시 시도 내려감 짐작 · 첫 요청 때 올라가요 비활성 · 라이선스 확인 전 CPU 실행 비노출 · P1 확인 불가

채움 · 빈 칸 · 굵은 테두리 · 사선 · 점선 · 회색 면으로 서로 다르게 보이고, 문구가 늘 함께 있다. "불러오는 중"은 오류가 아니므로 막대에 민트를 쓴다.

07 · 해야 할 것 · 하지 말 것

지키는 선

해야 할 것

  • 검정 주 버튼은 화면당 하나. 둘이 보이면 하나를 흰 버튼으로 바꾼다.
  • 새 구간은 먼저 어떤 컬러 블록에 둘지 정한다.
  • 컬러 블록 사이에는 반드시 흰 여백(96px)을 둔다.
  • 굵기는 320 · 330 · 340 · 480 · 540 · 700 중에서 고른다.
  • 모노체는 대문자·양의 자간으로 라벨에만 쓴다.
  • 상태와 오류는 색과 함께 문장이나 모양으로도 알린다.

하지 말 것

  • 회색 본문 글자를 쓰지 않는다. 위계는 굵기로 만든다.
  • 컬러 블록에 그림자를 넣지 않는다.
  • 팔레트 밖 색(주황, 빨강 경고 등)을 들이지 않는다.
  • 한 화면에 컬러 블록 둘을 동시에 보이지 않는다.
  • 네모 버튼을 만들지 않는다.
  • 점수, 발달 평가, 아이 간 비교를 보여 주지 않는다.
